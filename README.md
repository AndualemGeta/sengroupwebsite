# SEN Group Website

Complete Vite + React website for SEN Group, ready for GitHub and Netlify.

## Edit the website
Main editable file: `src/App.jsx`

Images are in: `public/images/`

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Netlify settings
Build command: `npm run build`

Publish directory: `dist`
